# CV Builder

A small full-stack web application where a user can register, save their professional details, and share a read-only CV through a public link. Built as a practical exercise.

**Stack:** C# / ASP.NET Core Web API, PostgreSQL with Entity Framework Core, React (Vite + TypeScript).

## Features

- Register, sign in and sign out
- Edit a profile: personal details, skills, work experience and education
- Preview the CV in a responsive template
- Create, update and revoke a public, hard-to-guess CV link
